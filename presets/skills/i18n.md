## 核心概念

- **文案外置**：用户可见文案一律走 i18n key，禁止硬编码在组件/页面
- **Key 语义化**：按模块/页面分层命名（`module.page.action`），禁止无意义 key
- **完整覆盖**：新增 key 必须同步所有语言文件；缺 key 视为缺陷
- **动态内容**：插值/复数/日期数字用 i18n 能力（`{var}`/plural/format），禁止手拼字符串

## 常用操作

1. 新增文案：在语言文件加 key（全语言同步）→ 组件用 `t('key')`
2. 带变量文案：用插值占位，禁止字符串拼接（顺序/复数问题）
3. 日期/金额：走 locale 格式化（时区/货币符号自动适配）
4. 修改文案：同步所有语言文件，保持 key 稳定（key 是契约）

## 常见问题与陷阱

- ❌ 硬编码中文/英文在代码 → 无法本地化；必须走 key
- ❌ 只加一种语言 → 其他语言缺 key 显示原始 key；全量同步
- ❌ 字符串拼接变量 → 语序错误；用插值
- ❌ 删 key 不清理引用 → 运行时空引用；先搜引用再删
- ❌ 日期用本地硬编码格式 → 时区/地区错误；用 locale 格式化
